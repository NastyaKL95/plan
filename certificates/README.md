# Сертификаты

Веб-приложение для выдачи именных сертификатов участникам мероприятий.

- **Администратор** загружает фон сертификата, мышью расставляет на нём надписи (ФИО, организация, номер, дата, код проверки, любой свой текст) и выбирает, какие поля заполняет слушатель.
- Для мероприятия создаётся **ссылка с ограниченным сроком действия**: начало и окончание, лимит выдач, по желанию кодовое слово.
- **Слушатель** открывает ссылку, вводит ФИО и организацию и сразу скачивает готовый PDF.
- У каждого сертификата есть сквозной номер и код. На странице проверки по коду видно, что сертификат подлинный и не аннулирован.
- **Реестр** выданных: поиск, выгрузка в CSV (открывается в Excel), повторное скачивание, аннулирование и ручная выдача.

PDF собирается на сервере без внешних библиотек. Кириллические шрифты Tinos (аналог Times New Roman) и Arimo (аналог Arial) встраиваются в файл только нужными символами, поэтому PDF весит 100–300 КБ и одинаково печатается везде.

## Требования

- PHP 8.0 или новее с расширениями `pdo_mysql`, `mbstring` и `zlib`. GD и Imagick не нужны.
- MySQL 5.7+ или MariaDB 10.3+.

## Установка

1. Скопируйте папку `certificates` на сервер. Корень сайта (document root) должен указывать на `certificates/public`.
2. Создайте пустую базу данных в кодировке `utf8mb4`.
3. Рядом с `config.php` создайте `config.local.php`:

   ```php
   <?php
   return [
       'db_host' => 'localhost',
       'db_name' => 'certificates',
       'db_user' => 'пользователь',
       'db_pass' => 'пароль',
       // полный адрес сайта, используется в ссылках для слушателей и в адресе проверки на сертификате
       'base_url' => 'https://cert.example.ru',
   ];
   ```

4. Дайте веб-серверу право записи в папку `storage/` и её подпапки (там хранятся фоны).
5. Откройте `https://ваш-сайт/admin/`. При первом входе приложение само создаст таблицы и предложит завести первого администратора.

Если корень сайта нельзя направить в `public`, закройте доступ к `src/`, `sql/`, `storage/` и `config*.php`. Для Apache файлы `.htaccess` уже лежат в этих папках.

## Как пользоваться

1. **Шаблоны → Новый шаблон.** Загрузите фон (JPG или PNG, для печати лучше 3508×2480 точек). Перетащите надписи на нужные места и нажмите «Предпросмотр PDF», чтобы проверить результат.
2. **Ссылки для слушателей → Создать ссылку.** Укажите срок действия и отправьте ссылку участникам.
3. **Реестр выданных** показывает, кто и когда получил сертификат.

Подстановки в тексте надписей:

| Подстановка | Что выводит |
|---|---|
| `{fio}`, `{org}` и свои поля | то, что ввёл слушатель |
| `{number}` | номер сертификата (начало номера и число цифр задаются в шаблоне) |
| `{date}` / `{date_long}` | дата выдачи: `13.11.2026` / `«13» ноября 2026 г.` |
| `{code}` | код проверки |
| `{verify_url}` | адрес страницы проверки с кодом |
| `{title}` | название шаблона |

Длинный текст сам уменьшается (до половины размера) и переносится на заданное число строк.

## Защита

- Пароли администраторов хранятся в виде хешей. После 5 неверных попыток вход блокируется на минуту.
- Все формы защищены CSRF-токеном.
- Действует лимит выдач с одного IP-адреса в час (`max_per_ip_hour`).
- Кодовое слово ссылки хранится в виде хеша, частый перебор блокируется.
- Повторная отправка тех же данных не создаёт дубль, а возвращает уже выданный сертификат.
