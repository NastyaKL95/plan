# Муниципальный этап ВсОШ по информатике, 9–11 классы (новый комплект)

Уникальные задания, построенные по структуре прошлогоднего комплекта `informatika_mun_25-26`, но с новыми сюжетами и чуть более высокой сложностью.

| № | Было (2025–26) | Стало (новый комплект) | В чём усложнение |
|---|----------------|------------------------|------------------|
| 1 | Самолёт (края ≤3, середина ≤4) | Кинотеатр (края ≤2, середина ≤5) | Другие ограничения, аккуратнее формула |
| 2 | Минимальный номер с произведением цифр N | Минимальный **чётный** номер с произведением N | Нужно собрать наименьшее чётное число из цифр |
| 3 | Городки (распил пополам **один** раз) | Трубы (распил пополам **сколько угодно** раз) | Сведение к нечётному ядру, счётчик `2^k` |
| 4 | Треугольники на сетке с диагоналями | Равнобедренные прямоугольные треугольники (катет 1..3) | Осевые и диагональные катеты, сумма по трём длинам |

## Файлы

- `zadaniya.md` — условия для участников
- `zadaniya.pdf` — то же в PDF
- `resheniya.md` — разбор и эталонные решения
- `solutions/` — код решений на Python 3
- `tests/` — простые тесты
- `podgotovka-12h/` — интенсив 12 часов, завязанный на комплект задач выше
- `kurs-olimpiada-12h/` — **отдельный курс 12 часов** (без муниципального комплекта): темы, разборы, практика, доп. задачи, Word/PPTX
- `variant-2/` — **вариант 2** муниципального этапа (сложнее примера): условия, разбор, решения, тесты, Word/PPTX/PDF
- `kurs-2-olimpiada-12h/` — **курс 2 на 12 часов** (новые темы: перебор, строки, жадность, бинпоиск, BFS, ДП) с реальными задачами ВсОШ/Codeforces
- `tools/office_utils.py` — общие функции сборки Word/PowerPoint
- `office/` — Word/PPTX для комплекта и старого интенсива

Каждая задача — **100 баллов**. Ограничения по времени/памяти: 1 с / 64 MB.

## Подготовка группы (12 часов)

См. [`podgotovka-12h/README.md`](podgotovka-12h/README.md):

- 6 блоков × 2 часа (формулы → цифры → массивы → сетка → стратегия → тур);
- конспекты-презентации в `podgotovka-12h/bloki/`;
- обзорная HTML-презентация `podgotovka-12h/prezentaciya-obzor.html`;
- практика `praktika/` и доп. задачи `bonus/`;
- шпаргалка ученику `razdatochnyj-material.pdf`.

## Отдельный курс 12 часов (быстрая группа, без нашего комплекта)

См. [`kurs-olimpiada-12h/`](kurs-olimpiada-12h/):

- ускоренный темп: короткая теория → практика → **реальные задачи ВсОШ/CF**;
- папка `realnye/` + `office/Realnye_olimpiadnye.docx`;
- темы: формулы, цифры, массивы, сетка, серии/два указателя, мини-тур;
- Word/PPTX в `kurs-olimpiada-12h/office/`.

## Вариант 2 муниципального этапа (сложнее примера)

См. [`variant-2/`](variant-2/):

| № | Задача | Тема | Что сложнее |
|---|--------|------|-------------|
| 1 | Зал с проходами | формула, округление вверх | параметры a, b вместо констант, числа до 10¹⁸ |
| 2 | Самый большой код | разложение на цифры, жадность с проверкой | наибольшее число не более чем из K цифр (с единицами) |
| 3 | Счастливые отрезки | префиксные суммы, остатки | отрицательные числа, n до 2·10⁵, ответ 64 бита |
| 4 | Квадраты на клетчатом поле | комбинаторика, суммы степеней | наклонные квадраты, n, m до 10⁹, ответ по модулю |

У каждой задачи есть подзадачи. Эталонные решения сверены с полным перебором: `python3 variant-2/tests/run_tests.py`.

## Курс 2: 12 часов, новые темы

См. [`kurs-2-olimpiada-12h/README.md`](kurs-2-olimpiada-12h/README.md):

- 6 блоков × 2 часа: перебор → строки → жадность и два указателя → бинарный поиск и НОД → BFS → ДП + мини-тур;

- Word и PowerPoint в `kurs-2-olimpiada-12h/office/`.
