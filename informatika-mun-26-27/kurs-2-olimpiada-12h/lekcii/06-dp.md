# Блок 6. Динамическое программирование + мини-тур (часы 10–12)

**Цель:** Строить решение через подзадачи: состояние, переход, база, порядок вычисления. Последний час — мини-тур по всем темам курса.

## Лекция

### Идея динамики

Если ответ для большой задачи складывается из ответов для меньших похожих задач — запоминаем ответы в массиве `dp` и не считаем одно и то же дважды.

Четыре вопроса для любой ДП:

1. **Состояние**: что означает `dp[i]` (или `dp[i][j]`)? Формулируйте словами!

2. **Переход**: как `dp[i]` выражается через уже посчитанные значения?

3. **База**: чему равны самые маленькие состояния?

4. **Порядок и ответ**: в каком порядке считать и где лежит ответ?

### Классические шаблоны

- **Количество способов**: лестница шагами 1, 2, 3 — `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`.

- **Минимальная стоимость**: кузнечик — `dp[i] = min(dp[i-1], dp[i-2]) + c[i]`.

- **Путь в таблице**: `dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + a[i][j]`.

- **Подпоследовательности**: НВП за \(O(n^2)\) — `dp[i] = 1 + max(dp[j])` по `j < i`, `a[j] < a[i]`.

- **Рюкзак 0/1**: `dp[w]` — лучшая стоимость при весе ≤ w; цикл по w **в обратном порядке**, чтобы предмет не взять дважды.

### Типичные ошибки

Забыли базу или недостижимые состояния (используйте −1 / −∞ для «невозможно»).

Неправильный порядок циклов (в рюкзаке прямой порядок превращает 0/1 в неограниченный).

Переполнение при подсчёте способов — берите ответ по модулю, если просят.

## Разобранный пример: Кузнечик

Кузнечик стоит на клетке 1 и прыгает на 1 или 2 клетки вперёд. За посещение клетки i он платит \(c_i\) (клетку 1 тоже оплачивает). Какую минимальную сумму он заплатит, чтобы попасть на клетку n?

| Вход | Выход |
|------|-------|
| `6`<br>`0 3 2 7 1 4` | `7` |

**Разбор по шагам:**

1. Состояние: `dp[i]` — минимальная сумма, чтобы оказаться на клетке i.
2. Переход: на клетку i можно прийти с i−1 или с i−2: `dp[i] = min(dp[i-1], dp[i-2]) + c[i]`.
3. База: `dp[0] = c[0]`, `dp[1] = dp[0] + c[1]`.
4. Ответ: `dp[n-1]`. Пример: 0 → 2 → 1 → 4 (клетки 1, 3, 5, 6), сумма 7.

```python
n = int(input())
c = list(map(int, input().split()))
dp = [0] * n
dp[0] = c[0]
for i in range(1, n):
    dp[i] = dp[i - 1] + c[i]
    if i >= 2:
        dp[i] = min(dp[i], dp[i - 2] + c[i])
print(dp[n - 1])
```

### Cut Ribbon

**Источник:** [Codeforces 189A — Cut Ribbon](https://codeforces.com/problemset/problem/189/A)

Ленту длины n режут на куски длины a, b или c. Максимальное количество кусков?

**Идея решения.** `dp[i]` — максимум кусков для длины i (−1, если нельзя). `dp[i] = max(dp[i-p] + 1)` по p ∈ {a, b, c}.

Эталонное решение: [`solutions/cf189a_ribbon.py`](../solutions/cf189a_ribbon.py)

### Boredom

**Источник:** [Codeforces 455A — Boredom](https://codeforces.com/problemset/problem/455/A)

Взяв число x, получаем x очков, но все числа x−1 и x+1 удаляются. Максимум очков?

**Идея решения.** Считаем cnt[v]. Для каждого значения v: «брать» (v·cnt[v] + лучший ответ без v−1) или «не брать». Это «разбойник на улице» по значениям.

Эталонное решение: [`solutions/cf455a_boredom.py`](../solutions/cf455a_boredom.py)
