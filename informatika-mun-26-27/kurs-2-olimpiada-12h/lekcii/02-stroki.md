# Блок 2. Строки и длинные числа (часы 2–4)

**Цель:** Уверенно обрабатывать строки посимвольно: подсчёт букв, группы одинаковых символов, арифметика «столбиком», системы счисления.

## Лекция

### Строка — это массив символов

`s[i]` — i-й символ, `len(s)` — длина. Код символа: `ord('a') = 97`, обратно `chr(97)`.

Номер буквы в алфавите: `ord(c) - ord('a')` — от 0 до 25. Так заводим массив счётчиков `cnt[26]`.

В Python строки неизменяемые: собирайте ответ в список и в конце делайте `''.join(parts)` — иначе `s += c` в цикле может работать за \(O(n^2)\).

### Группы одинаковых символов (серии)

Шаблон «два указателя»: `i` — начало серии, `j` двигаем, пока `s[j] == s[i]`. Длина серии `j - i`, затем `i = j`.

Применения: сжатие RLE (`aaab` → `a3b1`), самая длинная серия, «слишком много гласных подряд».

### Длинные числа

Числа длиннее 18 цифр не помещаются в `long long`. В Python `int` безразмерный, но на олимпиаде часто просят свою арифметику (как в «Лунной арифметике»).

Сложение столбиком: выравниваем строки нулями слева (`rjust`), идём справа налево, держим перенос.

Умножение столбиком: для каждой цифры второго числа — строка-произведение со сдвигом, затем сложение.

### Системы счисления

Из системы p в число: `x = x * p + digit` слева направо (схема Горнера).

Из числа в систему q: остатки `x % q`, затем `x //= q`, остатки читаем в обратном порядке.

Цифры больше 9: `DIG = '0123456789ABCDEF…'`.

## Разобранный пример: Сжатие RLE

Сожмите строку: каждую серию одинаковых букв замените на букву и длину серии.

| Вход | Выход |
|------|-------|
| `aaabccdddd` | `a3b1c2d4` |

**Разбор по шагам:**

1. Ставим `i = 0`. Пока `i < n`: двигаем `j` от `i`, пока символ тот же.
2. Записываем `s[i] + str(j - i)` в список частей, затем `i = j`.
3. В конце склеиваем части через `join`.
4. Сложность \(O(n)\): каждый символ просматривается один раз.

```python
s = input().strip()
parts = []
i = 0
while i < len(s):
    j = i
    while j < len(s) and s[j] == s[i]:
        j += 1
    parts.append(s[i] + str(j - i))
    i = j
print("".join(parts))
```

### Лунная арифметика

**Источник:** [ВсОШ, муниципальный этап 2024/25, 9–11 кл. (Казань, 5 декабря 2024)](https://tasks.olimpiada.ru/upload/files/tasks/73/2024/tasks-iikt-9-11-mun-belgor-24-25.pdf), задача B

В лунной арифметике сумма цифр — их максимум, произведение — минимум; многозначные числа складываются и умножаются «столбиком». Даны \(a, b \le 10^{100}\) — выведите лунные сумму и произведение.

**Идея решения.** Числа — строки. Сумма: выровнять нулями, взять max по разрядам. Произведение: для каждой цифры d второго числа строка `min(c, d)` по цифрам первого + сдвиг нулями, и все строки сложить лунным сложением. 169 + 248 = 269, 169 × 248 = 12468.

Эталонное решение: [`solutions/r_lunnaya.py`](../solutions/r_lunnaya.py)

### Магические слова

**Источник:** [ВсОШ, муниципальный этап 2019/20, 9–11 кл. (Владивосток)](https://tasks.olimpiada.ru/upload/files/tasks/73/2019/tasks-iikt-9-11-mun-vlad-19-0.pdf), задача D

Слово магическое, если в нём нет трёх гласных подряд и трёх согласных подряд. Какое наименьшее число букв нужно вставить, чтобы слово стало магическим? (Гласные: a, e, i, o, u, y.)

**Идея решения.** Разбиваем слово на серии «все гласные» / «все согласные». В серию длины L нужно вставить \(\lfloor (L-1)/2 \rfloor\) букв другого типа (после каждой второй буквы). magic → 0, filth → 1 (серия lth).

Эталонное решение: [`solutions/r_magicheskie.py`](../solutions/r_magicheskie.py)
