# Блок 5. Графы и поиск в ширину (BFS) (часы 8–10)

**Цель:** Хранить граф списками смежности, находить кратчайшие пути BFS в обычных графах, на клетчатых полях и в «неявных» графах состояний.

## Лекция

### Что такое граф и как его хранить

Граф — вершины и рёбра. Примеры: города и дороги, клетки поля и соседство, числа и операции.

**Список смежности**: `g[v]` — список соседей v. Память \(O(n + m)\) — подходит для \(n, m \le 2 \cdot 10^5\).

Матрица смежности \(n \times n\) годится только для \(n \le 2000\)–\(5000\).

### Поиск в ширину

BFS обходит вершины **слоями**: сначала на расстоянии 0, потом 1, 2, … Поэтому первое посещение = кратчайший путь (если все рёбра одинаковой длины).

Шаблон: `dist = [-1]*n; dist[s] = 0; q = deque([s])`; пока очередь не пуста — достаём v, для каждого соседа u с `dist[u] == -1` ставим `dist[u] = dist[v] + 1` и кладём в очередь.

Восстановление пути: запоминаем `par[u] = v`, затем идём от конца к началу по `par` и разворачиваем.

### BFS на клетчатом поле

Вершина — клетка (i, j), соседи — 4 направления: `for di, dj in ((1,0),(-1,0),(0,1),(0,-1))`.

Не забывайте проверку границ `0 <= a < n and 0 <= b < m` и стен.

### Мультиисточниковый BFS и 0-1 BFS

Несколько стартов (огонь в нескольких клетках, охранники на складах) — кладём **все** в очередь сразу с расстоянием 0.

Если рёбра стоят 0 или 1 — **0-1 BFS** с деком: ребро веса 0 кладём в начало (`appendleft`), веса 1 — в конец.

### Неявный граф

Вершины — состояния (число на экране, позиция коня), рёбра — допустимые действия. Граф не строим заранее, соседей вычисляем на лету. Важно ограничить множество состояний (например, числа до 2·max).

## Разобранный пример: Лабиринт

Поле n × m: `.` — проход, `#` — стена, S — старт, F — финиш. За какое минимальное число шагов (по сторонам клеток) можно дойти от S до F? Если нельзя — −1.

| Вход | Выход |
|------|-------|
| `4 5`<br>`S..#.`<br>`.#...`<br>`.#.#F`<br>`...#.` | `6` |

**Разбор по шагам:**

1. Находим S, ставим dist = 0, кладём в очередь.
2. Достаём клетку; если это F — ответ найден. Иначе проверяем 4 соседей: в поле, не стена, не посещена.
3. Путь в примере: вправо, вправо, вниз, вправо, вправо, вниз — 6 шагов.
4. Сложность \(O(n \cdot m)\): каждая клетка попадает в очередь не больше одного раза.

```python
from collections import deque

n, m = map(int, input().split())
g = [input() for _ in range(n)]
for i in range(n):
    for j in range(m):
        if g[i][j] == "S":
            start = (i, j)
dist = [[-1] * m for _ in range(n)]
dist[start[0]][start[1]] = 0
q = deque([start])
ans = -1
while q:
    i, j = q.popleft()
    if g[i][j] == "F":
        ans = dist[i][j]
        break
    for di, dj in ((1, 0), (-1, 0), (0, 1), (0, -1)):
        a, b = i + di, j + dj
        if 0 <= a < n and 0 <= b < m and g[a][b] != "#" and dist[a][b] == -1:
            dist[a][b] = dist[i][j] + 1
            q.append((a, b))
print(ans)
```

### Two Buttons

**Источник:** [Codeforces 520B — Two Buttons](https://codeforces.com/problemset/problem/520/B)

На экране число n. Красная кнопка умножает на 2, синяя вычитает 1. За сколько нажатий получить m?

**Идея решения.** Неявный граф: вершины — числа от 1 до 2·max(n, m), рёбра v → 2v и v → v−1. BFS из n. (Есть и жадное решение «с конца»: из m делим на 2, если чётное, иначе прибавляем 1.)

### Охрана крепости

**Источник:** [ВсОШ, муниципальный этап 2024/25, 9–11 кл. (Казань, 5 декабря 2024)](https://tasks.olimpiada.ru/upload/files/tasks/73/2024/tasks-iikt-9-11-mun-belgor-24-25.pdf), задача D

n складов, m дорог длины 1, k охранников: охранник на складе p с выносливостью h охраняет все склады на расстоянии ≤ h. Выведите все охраняемые склады (n, m, k ≤ 2·10^5).

**Идея решения.** BFS от каждого охранника — \(O(k(n+m))\), слишком долго. Делаем один общий обход: best[v] — наибольший «остаток выносливости», с которым кто-то пришёл в v. Обрабатываем вершины по убыванию остатка (корзины по h от большего к меньшему): из v с остатком h соседи получают h−1, если это улучшает их значение. Охраняемы все вершины с best ≥ 0. Каждая вершина раскрывается один раз — со своим наибольшим остатком (устаревшие записи в корзинах пропускаем), поэтому всё работает за \(O(n + m + \max h)\).

Эталонное решение: [`solutions/r_ohrana.py`](../solutions/r_ohrana.py)

### Solve The Maze

**Источник:** [Codeforces 1365D — Solve The Maze](https://codeforces.com/problemset/problem/1365/D)

В лабиринте есть хорошие (G) и плохие (B) люди, выход в правом нижнем углу. Можно ставить стены в пустые клетки. Можно ли сделать так, чтобы все G могли выйти, а ни один B — нет?

**Идея решения.** Окружаем каждого B стенами (в соседние пустые клетки). Если рядом с B стоит G — ответ No. Затем один BFS от выхода: все G должны быть достижимы, а B — нет.
