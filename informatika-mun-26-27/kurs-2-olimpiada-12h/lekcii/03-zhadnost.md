# Блок 3. Сортировка, жадность, два указателя (часы 4–6)

**Цель:** Понимать, когда жадный выбор оптимален (и как это доказать обменом), и уметь проходить отсортированный массив двумя указателями за O(n).

## Лекция

### Сортировка как подготовка

Сортировка стоит \(O(n \log n)\) и часто превращает сложную задачу в простой проход.

Python: `a.sort()`, `sorted(a, key=lambda x: x[1])`, сортировка пар — сначала по первому, затем по второму.

C++: `sort(a.begin(), a.end())`, для пар — компаратор или `pair<int,int>`.

### Жадный алгоритм и доказательство обменом

Жадность — на каждом шаге делаем локально лучший выбор и больше к нему не возвращаемся.

Чтобы убедиться, что жадность верна, используйте **аргумент обмена**: берём любое оптимальное решение, отличающееся от жадного, и показываем, что его можно поменять в сторону жадного, не ухудшив.

Классика: из отрезков-заявок выбрать максимум непересекающихся — сортируем по **концу** и берём, если не пересекается. Сортировка по началу или по длине — неверна (придумайте контрпример!).

### Два указателя

Указатели `i` и `j` двигаются только вперёд (или навстречу) → всего \(O(n)\) шагов.

- **Навстречу** по отсортированному массиву: пары с суммой ≤ S, лодки по двое.

- **Окно** `[left, right]` при положительных числах: двигаем `right`, пока сумма > лимита — сдвигаем `left`.

### Метод событий (сканирующая прямая)

Каждый отрезок [l, r) превращаем в два события: (l, +1) и (r, −1). Сортируем и идём слева направо, поддерживая текущее количество. Максимум = наибольшее число одновременно открытых отрезков.

При равных координатах −1 должно идти раньше +1, если концы не пересекаются (для полуинтервалов).

## Разобранный пример: Заявки на актовый зал

Есть n заявок на зал, каждая — полуинтервал [l, r). Выберите максимальное количество непересекающихся заявок.

| Вход | Выход |
|------|-------|
| `5`<br>`1 3`<br>`2 5`<br>`4 6`<br>`6 8`<br>`5 7` | `3` |

**Разбор по шагам:**

1. Сортируем заявки по времени окончания r.
2. Идём по списку; берём заявку, если её начало ≥ концу последней взятой.
3. Почему верно: первая заявка в оптимуме заменяется на заявку с самым ранним концом — остальные заявки останутся совместимыми (обмен).
4. Для примера: [1,3) ✓, [2,5) ✗, [4,6) ✓, [5,7) ✗, [6,8) ✓ → 3.

```python
n = int(input())
segs = [tuple(map(int, input().split())) for _ in range(n)]
segs.sort(key=lambda x: x[1])
cnt, last_end = 0, -10**18
for l, r in segs:
    if l >= last_end:
        cnt += 1
        last_end = r
print(cnt)
```

### Морской бой

**Источник:** [ВсОШ, муниципальный этап 2022/23, 9–11 кл. (Москва, 11 декабря 2022)](https://vos.olimpiada.ru/upload/files/Arhive_tasks/2022-23/mun/iikt/tasks-iikt-9-11-mun-msk-22-23.pdf), задача 4

Корабли едут влево (N штук) и вправо (M штук) с одинаковой скоростью, координаты чётные. Торпеда в момент t в точке x подбивает все корабли, находящиеся там. Подбейте все корабли минимальным числом торпед (вывести моменты и точки).

**Идея решения.** Два корабля, едущих в одну сторону, никогда не встречаются, поэтому одна торпеда подбивает не больше двух кораблей — «правый» r и «левый» l, причём только если r < l (встреча в момент (l−r)/2 в точке (l+r)/2). Нужно максимальное паросочетание: идём по r по возрастанию и берём наименьший свободный l > r (два указателя). Остальные корабли бьём по одному в момент 0.

Эталонное решение: [`solutions/r_morskoy_boy.py`](../solutions/r_morskoy_boy.py)

### Dragons

**Источник:** [Codeforces 230A — Dragons](https://codeforces.com/problemset/problem/230/A)

У Кирито сила s, драконы с силой x_i дают бонус y_i после победы. Можно ли победить всех в каком-то порядке?

**Идея решения.** Жадность: сражаемся с драконами по возрастанию силы. Если не можем победить самого слабого из оставшихся, то не победим никого.

### Books

**Источник:** [Codeforces 279B — Books](https://codeforces.com/problemset/problem/279/B)

Книги читаются подряд, начиная с любой; есть t минут. Сколько книг максимум можно прочитать?

**Идея решения.** Окно двух указателей на положительных числах: расширяем вправо, при сумме > t сдвигаем левый край.

Эталонное решение: [`solutions/cf279b_books.py`](../solutions/cf279b_books.py)
