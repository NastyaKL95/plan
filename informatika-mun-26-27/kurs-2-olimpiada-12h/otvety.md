# Ответы и подсказки: практика, задачи для быстрых, мини-тур

Все ответы на примерах проверены эталонными решениями из `solutions/` (`python3 build.py`, `python3 tests/run_tests.py`).

## Блок 1. Перебор и моделирование

- **1.1. Подмножества с суммой W** — Перебор масок от 0 до \(2^n-1\): {1,4} и {2,3}. Решение: `solutions/b1_p1_podmnozhestva.py`.
- **1.2. Часы-палиндромы** — Переведите время в минуты и переберите все минуты (не больше 1440). Строка `f"{h:02d}{m:02d}"`. Решение: `solutions/b1_p2_chasy.py`.
- **1.3. Перестановки без соседей** — Для n = 4: 2413 и 3142. Перебор всех \(n!\) перестановок. Решение: `solutions/b1_p3_perestanovki.py`.
- **1.4. Плюсы между цифрами** — Каждый из \(n-1\) промежутков: «+» или ничего → маска из \(n-1\) бит. 1+23 = 24; 11+1+1, 1+11+1, 1+1+11. Решение: `solutions/b1_d1_plyusy.py`.
- **1.5. Тройки с нулевой суммой** — Тройной цикл — \(n^3/6 \approx 1.3\cdot10^9\), много. Фиксируем k, а пары (j<k) считаем словарём: ищем, сколько раз встречалось \(-a_j-a_k\) левее j. \(O(n^2)\). Решение: `solutions/b1_d2_troyki.py`.

## Блок 2. Строки и длинные числа

- **2.1. Анаграммы** — Массив `cnt[26]`: +1 за буквы первого слова, −1 за буквы второго; все нули → YES. Решение: `solutions/b2_p1_anagrammy.py`.
- **2.2. Сложение столбиком** — Выравнивание `rjust`, перенос `carry`, не забыть перенос в конце. Решение: `solutions/b2_p2_stolbik.py`.
- **2.3. Самая длинная серия** — Тот же шаблон серий, что и в RLE. Решение: `solutions/b2_p3_blok.py`.
- **2.4. Палиндром из букв** — Нечётное количество может быть не больше чем у одной буквы. Левая половина — буквы по алфавиту по cnt/2, в середину — «нечётная» буква, справа — зеркало. Решение: `solutions/b2_d1_palindrom.py`.
- **2.5. Из системы p в систему q** — Горнер в десятичное, затем остатки от деления на q. Решение: `solutions/b2_d2_sistemy.py`.

## Блок 3. Сортировка, жадность, два указателя

- **3.1. Лодки** — Сортировка, самый тяжёлый едет с самым лёгким, если помещаются; иначе один. Решение: `solutions/b3_p1_lodki.py`.
- **3.2. Пары с суммой не больше S** — Сортировка и указатели навстречу: если a[i]+a[j] ≤ S, то все пары (i, i+1..j) подходят — прибавляем j−i. Решение: `solutions/b3_p2_pary.py`.
- **3.3. Сколько нужно аудиторий** — Метод событий: ответ = максимальное число одновременно идущих занятий. Событие (r, −1) сортируется раньше (r, +1). Решение: `solutions/b3_p3_auditorii.py`.
- **3.4. Очередь в столовой** — Сначала самых быстрых (по возрастанию \(t_i\)): порядок 1, 2, 3 → 1 + 3 + 6 = 10. Доказательство — обмен соседей. Решение: `solutions/b3_d1_ochered.py`.
- **3.5. Pair of Topics (Codeforces 1324D)** — Перенесём: \(c_i = a_i - b_i\), нужно \(c_i + c_j > 0\). Порядок пар не важен → сортируем c, указатели навстречу. Решение: `solutions/b3_d2_cf1324d.py`.

## Блок 4. Бинарный поиск и алгоритм Евклида

- **4.1. Сколько чисел на отрезке** — Сортировка один раз, затем `bisect_right(a, R) - bisect_left(a, L)`. Решение: `solutions/b4_p1_otrezok.py`.
- **4.2. Верёвки** — ok(L) = сумма `a_i // L` ≥ k — монотонна. Ищем последний true. Если невозможно, ответ 0. Решение: `solutions/b4_p2_verevki.py`.
- **4.3. НОД и НОК массива** — gcd(0, x) = x — удобное начальное значение. Решение: `solutions/b4_p3_nok.py`.
- **4.4. Уравнение** — Функция возрастает → 100 итераций вещественного бинпоиска на [0, max(1, C)]. Решение: `solutions/b4_d1_uravnenie.py`.
- **4.5. Таблица умножения (Codeforces 448D)** — Сколько чисел ≤ x: сумма по строкам `min(m, x // i)`. Бинпоиск по x — первый, где количество ≥ k. Решение: `solutions/b4_d2_cf448d.py`.

## Блок 5. Графы и поиск в ширину (BFS)

- **5.1. Компоненты связности** — Запускаем BFS из каждой непосещённой вершины: {1,2,3}, {4}, {5,6}. Решение: `solutions/b5_p1_komponenty.py`.
- **5.2. Кратчайший путь с восстановлением** — Массив `par`; соседей обходим в порядке возрастания. Решение: `solutions/b5_p2_put.py`.
- **5.3. Пожар** — Мультиисточниковый BFS: все F в очереди с нулём. Решение: `solutions/b5_p3_pozhar.py`.
- **5.4. Шахматный конь** — BFS по клеткам, 8 вариантов хода. Решение: `solutions/b5_d1_kon.py`.
- **5.5. Ломаем стены (0-1 BFS)** — Вес ребра: 1, если входим в стену, иначе 0. Дек: вес 0 → appendleft, вес 1 → append. Решение: `solutions/b5_d2_steny_01bfs.py`.

## Блок 6. Динамическое программирование + мини-тур

- **6.1. Лестница** — `dp[0] = 1`, `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`. Решение: `solutions/b6_p1_lestnica.py`.
- **6.2. Черепашка** — Первая строка и первый столбец — отдельные случаи. Решение: `solutions/b6_p2_cherepashka.py`.
- **6.3. Наибольшая возрастающая подпоследовательность** — Например, 3 4 5 9 или 1 4 5 6. \(O(n^2)\). Решение: `solutions/b6_p3_nvp.py`.
- **6.4. Рюкзак** — Предметы весов 5 и 2: 8 + 3 = 11. Цикл по весу — от W вниз. Решение: `solutions/b6_d1_ryukzak.py`.
- **6.5. Пути с препятствиями** — `dp[i][j] = dp[i-1][j] + dp[i][j-1]`, для # — 0. Решение: `solutions/b6_d2_puti.py`.

## Мини-тур

- **М1. Плитка (формула)** — ⌈a/k⌉ · ⌈b/k⌉, деление с округлением вверх `(a + k - 1) // k`. Решение: `solutions/m1_plitka.py`.
- **М2. Схлопывание (строки, стек)** — Стек: если верх стека равен текущей букве — снимаем, иначе кладём. \(O(n)\). Решение: `solutions/m2_dubli.py`.
- **М3. Подотрезки с суммой S (два указателя)** — Окно: числа положительные, сумма монотонна. [2,3] и [5]. Решение: `solutions/m3_summa_s.py`.
- **М4. Острова (BFS)** — BFS из каждой непосещённой клетки суши. Решение: `solutions/m4_ostrova.py`.
