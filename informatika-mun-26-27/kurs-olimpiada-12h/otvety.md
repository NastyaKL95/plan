# Ответы и краткие идеи

## Практика 1
- P1A/P1B: `(n + k - 1) // k`
- P1C: `p + 1`

## Практика 2
- P2A: сумма цифр в цикле / по строке
- P2B: `10→19`, `20→299`, `9→9` (девятки справа, остаток слева)
- P2C: `36→49`, `1→1`, `13→-1`

## Практика 3
- P3A: `2 2` на примере
- P3B: `3`
- P3C: размер множества

## Практика 4
- P4A: `1`, `18` для (2,3): 2*3/2 * 3*4/2 = 3*6 = 18
- P4B: `5`, `8`
- P4C: `n+m-gcd(n,m)` → `2`, `4`

## Практика 5
- P5A: `pref[r]-pref[l-1]`
- P5B: `3` для `1 2 1 3` и S=5
- P5C: `4` для `1 2 3` и S=3

## Мини-тур (учебные)
- T1: `(n+k-1)//k`

## Реальные задачи — ответы / идеи
- **R1 Самолёт:** `max(1, 1+(n-3)//4)`; пример 10→2
- **R2 Речные прогулки:** минимизировать `|(i-1)a-(n-i)b|` по `i∈[2..n-1]`; оптимально около `(a+n*b)/(a+b)`; пример →3
- **R3 Кино:** ожидание `(p - M%p)%p` для периодов 15/10/5; пример →18
- **R4 Престижный номер:** 70→257, 101→-1
- **R5 Пароль:** 20→45, 1→11; при невозможности `No solution`
- **R6 Ожерелье:** примеры →1 и →2
- **R7 Порядок:** примеры →7, 13, 100
- **R8 Треугольники:** `8nm + 2(n-1)m + 2n(m-1) + 4(n-1)(m-1)`; 1×1→8, 3×5→196
- **R10 CF 580A:** пример →3
- **R12 Майки и носки:** разбор случаев по цветам; в примере условия часто `3 4`
