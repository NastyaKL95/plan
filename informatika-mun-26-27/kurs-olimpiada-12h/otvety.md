# Ответы и краткие идеи

## Практика 1
- P1A/P1B: `(n + k - 1) // k`
- P1C: `p + 1`

## Практика 2
- P2A: сумма цифр в цикле / по строке
- P2B: `10→19`, `20→299`, `9→9` (девятки справа, остаток слева)
- P2C: `36→49`, `1→1`, `13→-1`

## Практика 3
- P3A: `2 2` на примере
- P3B: `3`
- P3C: размер множества

## Практика 4
- P4A: `1`, `18` для (2,3): 2*3/2 * 3*4/2 = 3*6 = 18
- P4B: `5`, `8`
- P4C: `n+m-gcd(n,m)` → `2`, `4`

## Практика 5
- P5A: `pref[r]-pref[l-1]`
- P5B: `3` для `1 2 1 3` и S=5
- P5C: `4` для `1 2 3` и S=3

## Мини-тур
- T1: `(n+k-1)//k`
- T2: жадность 9..2
- T3: Counter + ничья в сторону меньшего
- T4: сумма по стороне квадрата
- Примеры T4: `3 2 → (3)(2)+(2)(1)=6+2=8`
