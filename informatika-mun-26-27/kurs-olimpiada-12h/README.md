# Курс подготовки к олимпиаде по информатике — 12 часов

**Самостоятельный курс** для 9–11 классов. Не привязан к комплекту задач муниципального этапа: свои темы, свои разобранные примеры, своя практика и дополнительные задачи.

## Расписание

| Блок | Часы | Тема |
|------|------|------|
| 1 | 0–2 | Формулы, округление вверх, «упаковка» |
| 2 | 2–4 | Цифры числа: сумма, произведение, конструкция |
| 3 | 4–6 | Массивы и частоты |
| 4 | 6–8 | Подсчёт фигур на сетке |
| 5 | 8–10 | Префикс-суммы и два указателя |
| 6 | 10–12 | Мини-тур + разбор |

В каждом блоке: **объяснение темы → разбор задачи → практика → дополнительные задачи** (для тех, кто быстрее).

## Папка

- `programma.md` — тайминг для преподавателя
- `temy/` — подробные разборы тем и учебных задач
- `praktika/` — задачи для группы
- `dopolnitelno/` — дополнительные задачи на те же темы
- `otvety.md` — ответы и краткие идеи
- `solutions/` — эталонный код к ключевым задачам
- `office/` — **Word и PowerPoint**
