# Тема 3. Массивы и частоты (4–6 часов)

## О чём тема

Дан список чисел. Нужно что-то посчитать: сколько раз встречается значение, какая самая частая величина, сколько подряд одинаковых, суммы на отрезках (позже — префиксы).

## Зачем на олимпиаде

`n` до \(10^5\)–\(10^6\) ⇒ решение должно быть примерно линейным. Словарь частот / один проход — базовый инструмент.

## Как рассуждать

1. Нужны ли все элементы или достаточно частот?
2. Если порядок важен (подряд идущие) — один проход с «текущей серией».
3. Если порядок не важен — `Counter` / словарь.
4. Ничья: внимательно читать («меньшее», «большее», «любое»).

---

## Разбор учебной задачи A. «Самое частое»

**Условие.** Дан массив из `n` чисел (\(1 \le n \le 10^5\)). Найдите значение, которое встречается чаще всего. Если таких несколько — выведите **наименьшее**.

**Выход:** два числа — частота и значение.

```python
from collections import Counter
n = int(input())
a = list(map(int, input().split()))
cnt = Counter(a)
best_c, best_v = -1, 10**18
for v, c in cnt.items():
    if c > best_c or (c == best_c and v < best_v):
        best_c, best_v = c, v
print(best_c, best_v)
```

**Пример:** `1 2 2 3 3` → частота 2 у чисел 2 и 3 → ответ `2 2`.

---

## Разбор учебной задачи B. «Самая длинная серия»

**Условие.** Найти максимальную длину подряд идущих равных элементов.

```python
n = int(input())
a = list(map(int, input().split()))
best = cur = 1
for i in range(1, n):
    if a[i] == a[i - 1]:
        cur += 1
        best = max(best, cur)
    else:
        cur = 1
print(best)
```

**Пример:** `1 1 2 2 2 1` → `3`.

## Что уметь к концу темы

- Писать частотный подсчёт и обработку ничьей.
- Находить серии подряд за один проход.
- Не скатываться в O(n²) при больших n.
