# Тема 4. Подсчёт на клетчатой сетке (6–8 часов)

## О чём тема

Нужно посчитать, сколько на сетке `n×m` клеток (или `(n+1)×(m+1)` узлов) фигур определённого вида: прямоугольников, квадратов и т.п.

Перебором при больших `n, m` не обойтись — нужна **формула**.

## Зачем на олимпиаде

Учит аккуратному комбинаторному счёту: зафиксировать размер, число положений, иногда ориентации.

## Как рассуждать

1. Что является «клеткой», а что «узлом»?
2. Зафиксируй размер фигуры.
3. Посчитай, в скольких местах она помещается: обычно `(n-s+1)*(m-s+1)`.
4. Просуммируй по всем допустимым размерам.
5. Проверь формулу на маленьких сетках вручную.

---

## Разбор учебной задачи A. «Прямоугольники»

**Условие.** Сетка из `n` строк и `m` столбцов клеток. Сколько различных прямоугольников, стороны которых идут по линиям сетки?

Прямоугольник задаётся выбором двух горизонтальных границ из `n+1` линий? Удобнее: выбрать непрерывный набор строк длины `h` и столбцов длины `w`.

Число способов выбрать полосу высоты `h`: `(n-h+1)`, ширины `w`: `(m-w+1)`.

Итого:
\[\sum_{h=1}^{n}\sum_{w=1}^{m}(n-h+1)(m-w+1) = \frac{n(n+1)}{2}\cdot\frac{m(m+1)}{2}.\]

```python
n = int(input()); m = int(input())
print(n * (n + 1) // 2 * m * (m + 1) // 2)
```

**Примеры:** `1 1 → 1`, `1 2 → 3`, `2 2 → 9`.

---

## Разбор учебной задачи B. «Квадраты по осям»

Только квадраты: сторона `s = 1..min(n,m)`.

\[\sum_{s=1}^{\min(n,m)}(n-s+1)(m-s+1).\]

```python
n = int(input()); m = int(input())
ans = 0
for s in range(1, min(n, m) + 1):
    ans += (n - s + 1) * (m - s + 1)
print(ans)
```

**Пример:** `2 2 → 5` (четыре 1×1 и один 2×2).
