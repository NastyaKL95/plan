# Тема 5. Префикс-суммы и два указателя (8–10 часов)

## О чём тема

**Префикс-суммы:** заранее посчитать суммы начал массива, чтобы сумму на отрезке `[l, r]` узнавать за O(1).

**Два указателя:** двигаем левую и правую границу окна по массиву (часто отсортированному или по неотрицательным числам) и поддерживаем инвариант (сумму, количество…).

## Зачем на олимпиаде

Много задач «сумма на отрезке», «самый длинный кусок с суммой ≤ S», «число пар с суммой = X» решаются именно так, а не вложенными циклами.

## Как рассуждать: префиксы

Пусть `pref[0]=0`, `pref[i] = a[0]+…+a[i-1]`.  
Тогда сумма `a[l]+…+a[r]` (0-индексация) = `pref[r+1]-pref[l]`.

---

## Разбор учебной задачи A. «Суммы на отрезках»

**Условие.** Дан массив `a` длины `n` и `q` запросов `l r` (1-индексация, включительно). Для каждого запроса вывести сумму на отрезке.

\(n, q \le 10^5\).

```python
n, q = map(int, input().split())
a = list(map(int, input().split()))
pref = [0]
for x in a:
    pref.append(pref[-1] + x)
for _ in range(q):
    l, r = map(int, input().split())
    print(pref[r] - pref[l - 1])
```

---

## Разбор учебной задачи B. «Самый длинный кусок с суммой ≤ S»

**Условие.** Массив из **неотрицательных** чисел. Найти максимальную длину подотрезка с суммой ≤ `S`. Если нельзя — 0.

**Идея двух указателей.** Двигаем правый конец; пока сумма > S, двигаем левый.

```python
n, S = map(int, input().split())
a = list(map(int, input().split()))
left = 0
cur = 0
best = 0
for right in range(n):
    cur += a[right]
    while cur > S and left <= right:
        cur -= a[left]
        left += 1
    best = max(best, right - left + 1)
print(best)
```

**Пример:** `S=5`, массив `1 2 3 2 1` → кусок `2 3` или `3 2` длины 2; также `2 1`… Максимум: `1 2 1`? Не подряд. Подряд: `2 3`=5 длина 2; `3 2`=5; `1 2 3`=6>5. Ответ 2.  
Другой: `1 1 1 1` и S=3 → ответ 3.
