# Тема 2. Цифры числа (2–4 часа)

## О чём тема

Число можно разобрать на цифры и собрать заново. Типичные цели:

- сумма цифр;
- произведение цифр;
- **минимальное** / **максимальное** число с заданной суммой или произведением цифр.

## Зачем на олимпиаде

Учит жадности: правильный локальный выбор (какую цифру взять) даёт глобально верный ответ.

## Как рассуждать при сумме цифр = S

**Максимальное число** длины ровно `L` с суммой цифр `S` (если возможно):

- сумма должна быть от 1 до `9L` (или 0 для числа 0);
- чтобы число было максимальным — слева ставим как можно большие цифры.

**Минимальное число** с суммой цифр `S` (без ведущих нулей):

- хотим короткую запись? Нет — для минимума как **числа** нужна **наименьшая длина**, а при равной длине — наименьший лексикографический вид.
- классика: набрать сумму единицами и «добить» старшую/младшую цифру; удобный способ — класть справа как можно больше девяток, слева оставить маленькую ненулевую.

## Разбор учебной задачи A. «Минимальное число с суммой цифр S»

**Условие.** Дано `S` (\(1 \le S \le 100\)). Найдите наименьшее натуральное число, сумма цифр которого равна `S`.

**Идея.** Чем меньше длина и чем меньше старшие разряды — тем меньше число. Оптимально: почти все цифры — девятки справа, а слева одна цифра `S % 9` (если не 0), либо 9, если `S` делится на 9.

Проще алгоритм:

1. Если `S <= 9` → ответ само `S`.
2. Иначе набираем справа девятки, пока сумма большая, а оставшееся кладём в старший разряд.

```python
S = int(input())
if S < 10:
    print(S)
else:
    digits = []
    while S > 9:
        digits.append(9)
        S -= 9
    digits.append(S)
    digits.reverse()  # старшая цифра слева
    print(''.join(map(str, digits)))
```

Подождите: если класть девятки в младшие разряды, для минимума нужно:

- оставшуюся цифру (1..9) поставить **первой**;
- дальше нули? Нет — для минимума при фиксированной сумме **нельзя** вставлять нули просто так: нули увеличивают длину и могут помочь, если сдвинуть массу вправо…

Классический минимальный результат для суммы S без ограничения длины:

- число из цифр, сумма = S, без ведущего нуля, минимальное как integer:
- берём как можно больше девяток **справа**, слева — остаток.

Пример: S=20 → остаток 2, две девятки → `299`.  
S=10 → `19`.  
S=18 → `99`.

Код выше с `digits.append(9)` затем `append(S)` и `reverse` даёт для S=20: digits=[9,9,2] → reverse → `299`. Верно.

## Разбор учебной задачи B. «Произведение цифр = N»

Разложить `N` на множители-цифры от 9 к 2. Если не получилось — `-1`. Цифры отсортировать по возрастанию → минимальное число.

Пример: `N=36 → 49` (или `66`? 4·9=36, жадность даёт 9 и 4 → `49`; 6·6=36 → `66` больше).

```python
N = int(input())
if N == 0:
    print(10)
elif N == 1:
    print(1)
else:
    d = []
    for x in range(9, 1, -1):
        while N % x == 0:
            N //= x
            d.append(x)
    print(-1 if N != 1 else int(''.join(map(str, sorted(d)))))
```
