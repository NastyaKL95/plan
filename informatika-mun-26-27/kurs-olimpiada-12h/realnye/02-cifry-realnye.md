# Реальные задачи · Цифры

## R4. Престижный номер
**Источник:** ВсОШ, муниципальный этап, Москва, 2022/23, задача 3  
**PDF:** https://vos.olimpiada.ru/upload/files/Arhive_tasks/2022-23/mun/iikt/tasks-iikt-9-11-mun-msk-22-23.pdf

Минимальное натуральное число, произведение цифр которого = `N` (`1 ≤ N ≤ 10¹⁸`). Если нельзя — `-1`.

Примеры: `70 → 257`, `101 → -1`.

**Идея:** жадное разложение на цифры 9..2, затем сортировка по возрастанию. Для `N=1` ответ `1`.

## R5. Пароль
**Источник:** ВсОШ, муниципальный этап, Владивосток, 2019/20, задача B  
**PDF:** https://tasks.olimpiada.ru/upload/files/tasks/73/2019/tasks-iikt-9-11-mun-vlad-19-0.pdf

То же по сути, но пароль **не короче 2 цифр**. При `N < 10` ответ `10+N` (например `1 → 11`). Если нельзя — `No solution`.  
`1 ≤ N ≤ 2·10⁶`.

Примеры: `20 → 45`, `1 → 11`.

**Отличие от R4:** ограничение на длину ≥ 2 и текст ответа при невозможности.
