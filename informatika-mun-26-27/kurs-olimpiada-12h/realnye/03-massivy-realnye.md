# Реальные задачи · Массивы / последовательности

## R6. Ожерелье и браслеты
**Источник:** ВсОШ, муниципальный этап, Владивосток, 2019/20, задача C  
**PDF:** https://tasks.olimpiada.ru/upload/files/tasks/73/2019/tasks-iikt-9-11-mun-vlad-19-0.pdf

Круговое ожерелье из `n` бусин (0 — чёрная, 1 — золотая). Нужны браслеты длины `k` из **подряд идущих золотых**. Сколько максимум таких непересекающихся кусков можно вырезать (круг!)?

Примеры:
- `n=9 k=3`, `0 1 1 1 0 0 0 1 1` → `1`
- `n=9 k=3`, `0 1 1 1 1 0 1 1 1` → `2`

**Идея:** удвоить массив (для круга) или аккуратно обработать стык; жадно резать серии единиц кусками по `k`.

## R7. Порядок во всём
**Источник:** ВсОШ, муниципальный этап, Москва, 2024/25, задача 3  
**PDF:** https://vos.olimpiada.ru/upload/files/Arhive_tasks/2024-25/mun/iikt/tasks-iikt-9-11-mun-msk-24-25.pdf

Даны `n` чисел (`2 ≤ n ≤ 3·10⁵`). Можно дописывать цифры **в конец** некоторых чисел, чтобы последовательность стала неубывающей. Минимизировать **последнее** число после дописываний.

Примеры:
- `1 5 7 → 7`
- `13 1 → 13`
- `20 2 1 → 100`

**Идея:** идти слева направо, для текущего числа найти минимальное число ≥ предыдущего, полученное дописыванием цифр (или само число, если уже ≥).
