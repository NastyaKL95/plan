# Реальные задачи · Формулы

## R1. Самолёт
**Источник:** ВсОШ, муниципальный этап, Москва, 2022/23, 9–11, задача 1  
**PDF:** https://vos.olimpiada.ru/upload/files/Arhive_tasks/2022-23/mun/iikt/tasks-iikt-9-11-mun-msk-22-23.pdf

В ряду `n` кресел. У иллюминаторов ≤ 3 кресла, между проходами ≤ 4, проход ≥ 1. Минимальное число проходов.  
`1 ≤ n ≤ 2·10⁹`.

Пример: `10 → 2`.

**Идея:** max при `p` проходах = `6 + 4(p-1)`; ответ `max(1, 1+(n-3)//4)`.

## R2. Речные прогулки
**Источник:** ВсОШ, муниципальный этап, Москва, 2024/25, задача 1  
**PDF:** https://vos.olimpiada.ru/upload/files/Arhive_tasks/2024-25/mun/iikt/tasks-iikt-9-11-mun-msk-24-25.pdf

`n` пристаней (`3 ≤ n ≤ 2·10⁹`). Старт на промежуточной пристани `i` (не 1 и не n). Вверх: `(i-1)*a` минут, вниз: `(n-i)*b`, `1 ≤ b < a ≤ 2·10⁹`. Найти `i`, минимизирующий `| (i-1)a − (n-i)b |`.

Пример: `n=8, a=7, b=3 → 3`.

**Идея:** оптимальная точка около `i ≈ (a + n·b)/(a+b)`; проверить пару соседних целых (и границы 2..n−1). При больших n — формула, без цикла по n.

## R3. Кино
**Источник:** ВсОШ, муниципальный этап, Владивосток, 2019/20, задача A  
**PDF:** https://tasks.olimpiada.ru/upload/files/tasks/73/2019/tasks-iikt-9-11-mun-vlad-19-0.pdf

Три фильма длительностями X, Y, Z; сеансы каждые 15 / 10 / 5 минут с 10:00. Миша пришёл в 10:M. Минимум (ожидание + длительность).

Пример: `X=25,Y=10,Z=20,M=12 → 18`.

**Идея:** ожидание фильма с периодом `p`: `(p - M % p) % p`.
