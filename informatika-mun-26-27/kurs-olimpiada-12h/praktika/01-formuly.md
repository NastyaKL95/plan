# Практика · Тема 1. Формулы

## P1A. Страницы

Нужно прочитать `n` страниц, за день успеваете `k`. Сколько дней минимум?

Вход: `n k` (\(1 \le k \le n \le 10^{18}\)).  
Примеры: `10 3 → 4`, `10 10 → 1`.

## P1B. Коробки

`n` яблок, в коробку кладут по `m`. Сколько коробок? (Последняя может быть неполной.)

Вход: `n m`. Примеры: `20 6 → 4`, `5 5 → 1`.

## P1C. Забор

Между `s` столбами нужно `s-1` промежутков. Для забора длины в `p` промежутков сколько столбов?  
Вход: `p` (\(1 \le p \le 10^9\)). Выход: `p+1`.  
Пример: `7 → 8`.

*(Простая формула — на «узнавание» вида ответа.)*
