# Практика · Тема 5. Префиксы и два указателя

## P5A. Префикс-суммы

`n q`, массив, затем `q` запросов `l r` (1-индексация) — суммы отрезков.  
Пример: массив `1 2 3 4`, запрос `2 4 → 9`.

## P5B. Окно суммы ≤ S

Неотрицательный массив, макс. длина подотрезка с суммой ≤ `S`.  
Пример: `S=5`, `1 2 1 3 → 3` (кусок `1 2 1`).

## P5C. Число подотрезков с суммой ≤ S

Неотрицательный массив. Сколько подотрезков имеют сумму ≤ `S`?  
Идея: два указателя + для каждого right число left.  
Пример: `1 2 3`, `S=3` → `[1],[2],[3],[1,2]` → 4.
