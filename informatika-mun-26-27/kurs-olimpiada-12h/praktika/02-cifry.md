# Практика · Тема 2. Цифры

## P2A. Сумма цифр

Дано число `x` (\(0 \le x \le 10^{18}\), как строка или целое). Выведите сумму его цифр.  
Пример: `205 → 7`.

## P2B. Минимальное с суммой S

Наименьшее натуральное число с суммой цифр `S` (\(1 \le S \le 100\)).  
Примеры: `10 → 19`, `20 → 299`, `9 → 9`.

## P2C. Произведение = N

Минимальное число с произведением цифр `N` (\(1 \le N \le 10^{18}\)), иначе `-1`.  
Примеры: `36 → 49`, `1 → 1`, `13 → -1`.
