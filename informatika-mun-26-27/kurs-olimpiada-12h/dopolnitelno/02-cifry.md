# Дополнительно · Тема 2

## D2A. Максимальное число из цифр

Дано число как строка. Переставьте цифры так, чтобы получилось максимальное число (ведущие нули допустимы только если всё нули — иначе обычная сортировка по убыванию).  
Пример: `1203 → 3210`.

## D2B. Число с суммой S и ровно L цифр

Минимальное L-значное число с суммой цифр S (без ведущего нуля). Если нельзя — `-1`.  
\(1 \le L \le 100\), \(0 \le S \le 900\).

Идея: младшие разряды набиваем 9, старший ≥1, сумма остатка должна сойтись.
