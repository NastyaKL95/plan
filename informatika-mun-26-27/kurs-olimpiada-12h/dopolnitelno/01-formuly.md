# Дополнительно · Тема 1

## D1A. Два размера коробок

Есть коробки вместимости `a` и `b`. Нужно упаковать ровно `n` предметов, используя любые количества коробок обоих типов (можно 0 одного типа). Возможно ли? Вывести `Yes`/`No`.

\(1 \le a,b \le 10^6\), \(1 \le n \le 10^{12}\) — аккуратно, можно перебрать число коробок типа `a` до `n/a`, проверяя остаток `% b` (если a маленькое) или использовать идею линейных комбинаций / цикл по min(a,b).

Упрощённый вариант для занятия: `a,b ≤ 1000`, `n ≤ 10^6`.

## D1B. Минимум дней с ростом нормы

В день 1 читаете `k` страниц, каждый следующий день на 1 больше, пока не прочтёте `n`. Сколько дней?  
Можно бинарным поиском по числу дней или формулой суммы арифметической прогрессии.
