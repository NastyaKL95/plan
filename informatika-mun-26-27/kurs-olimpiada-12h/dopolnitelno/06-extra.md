# Дополнительно после мини-тура

## E1. Смешанная формула

`n` пассажиров, купе по 4 места и плацкарт по 6. Можно использовать оба типа. Минимальное число вагонных «секций» (купе+плацкарт), чтобы вместить всех?  
Точнее: минимизировать `c+p` при `4c+6p ≥ n`, `c,p ≥ 0`. Перебор малого числа.

## E2. Цифры + проверка

Среди чисел от `1` до `m` сколько имеют сумму цифр = `S`? (`m ≤ 10^6` — перебор; для больших — идея digit DP на дом).

## E3. Частоты на префиксах

Для каждого префикса массива вывести текущую моду (значение с макс. частотой; ничья — меньшее). `n ≤ 10^5`.
