# Программа (для преподавателя)

Формат: 6 × 2 часа. Можно 2 дня по 6 часов или 3 дня по 4 часа.

## Общий принцип блока (120 мин)

| Мин | Что делаем |
|-----|------------|
| 0–20 | Тема простыми словами + зачем на олимпиаде |
| 20–50 | Разбор 1–2 учебных задач у доски / в редакторе |
| 50–95 | Практика группы (`praktika/`) |
| 95–115 | Доп. задачи для быстрых (`dopolnitelno/`) + помощь остальным |
| 115–120 | Сверка ответов, 2–3 типичные ошибки |

## Блоки

1. **Формулы** — `temy/01-formuly.md`
2. **Цифры** — `temy/02-cifry.md`
3. **Массивы** — `temy/03-massivy.md`
4. **Сетка** — `temy/04-setka.md`
5. **Префиксы и два указателя** — `temy/05-prefix-dva-ukazatelya.md`
6. **Мини-тур** — `temy/06-mini-tur.md` (4 новые задачи курса)

Кто закончил практику раньше — сразу `dopolnitelno/NN-...`, не ждать группу.
