# Программа интенсива (для преподавателя)

**Цель:** уверенно решать задачи муниципального уровня: O(1)/O(n) формулы, жадные конструкции, частоты, комбинаторный подсчёт.

**Формат:** 6 × 2 часа (можно 2 дня по 6 часов или 3 дня по 4 часа).

---

## Блок 1. Формулы и моделирование (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–15 | Вводная: что проверяют на муниц. этапе; ввод/вывод; ограничения → выбор алгоритма |
| 15–40 | Тема: «упаковка с ограничениями». Вывод формулы для кинотеатра на доске |
| 40–55 | Разбор №1 из комплекта + крайние случаи (n=1, n=4, n=5, 2·10⁹) |
| 55–90 | Практика: `praktika/01-formuly.md` (задачи A–C) |
| 90–110 | Бонус: `bonus/01-formuly-hard.md` |
| 110–120 | Сверка ответов, типичные ошибки (целочисленное деление, off-by-one) |

## Блок 2. Цифры и конструкция числа (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–20 | Произведение/сумма цифр; почему жадность с 9→2 даёт минимальное число |
| 20–45 | Разбор «Чётный артикул»: набор цифр → минимальное чётное |
| 45–75 | Практика: `praktika/02-cifry.md` |
| 75–100 | Бонус: палиндром / ограничение длины K |
| 100–120 | Мини-квиз: 5 чисел N → ответ устно |

## Блок 3. Массивы, частоты, распилы (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–25 | Сжатие одинаковых, словарь частот, «нечётное ядро» a=d·2^k |
| 25–50 | Разбор «Трубы»; сравнение с одноразовым распилом (городки) |
| 50–90 | Практика: `praktika/03-massivy.md` |
| 90–110 | Бонус: распил на 2 или 3 части |
| 110–120 | Разбор ошибок по TL (n=1e5) |

## Блок 4. Комбинаторика на сетке (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–30 | Счёт фигур: ориентации × позиции; формула без циклов по n=1e8 |
| 30–55 | Разбор «Катеты на сетке» (оси + 45°) |
| 55–95 | Практика: `praktika/04-kombinatorika.md` |
| 95–115 | Бонус: квадраты / прямоугольники на сетке |
| 115–120 | Чеклист «как выводить формулу по маленьким n,m» |

## Блок 5. Стратегия олимпиады + микс (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–20 | Тактика: порядок задач, тесты с краёв, проверка на примерах |
| 20–40 | Чтение условия «как следователь»: ограничения → идея |
| 40–100 | Микс из 4 коротких задач (`praktika/05-miks.md`), кто быстрый — бонус |
| 100–120 | Общий разбор 1–2 застрявших задач |

## Блок 6. Тренировочный тур (2 ч)

| Мин | Что делаем |
|-----|------------|
| 0–10 | Правила тура, сдача, что писать в черновик |
| 10–100 | Контест: 4 задачи комплекта + опционально бонус D |
| 100–120 | Разбор тура, план самостоятельной подготовки дальше |
