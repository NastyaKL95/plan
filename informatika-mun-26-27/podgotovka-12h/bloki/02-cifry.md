## Слайд 1. Что умеем делать с цифрами

- Произведение / сумма / количество цифр.
- Собрать **минимальное** или **максимальное** число с заданным свойством.
- Ключ: сначала найти **мультимножество цифр**, потом **правильно их упорядочить**.

---

## Слайд 2. Классика: произведение цифр = N

Жадность: делим \(N\) на цифры от 9 к 2.

- Если в конце осталось не 1 → невозможно (`-1`).
- Цифры в порядке **возрастания** → минимальное число.
- Почему большие цифры? Короче длина → меньше число.

```text
N=70 → 70/7=10, 10/5=2, 2/2=1 → цифры {7,5,2} → 257
N=101 → не делится → -1
```

---

## Слайд 3. Усложнение: число должно быть чётным

Набор цифр тот же. Число чётно ⇔ последняя цифра ∈ {2,4,6,8}.

Алгоритм:

1. Получить жадный набор.
2. Если нет чётной цифры → `-1`.
3. Перебрать, какую чётную поставить в конец; остаток отсортировать по возрастанию; взять минимум.

**Пример:** 70 → {2,5,7} → единственный чётный конец 2 → **572** (не 257!).

**Пример:** 16 → {8,2} → кандидаты 28 и 82 → **28**.

---

## Слайд 4. Разбор «Чётный артикул» (код-идея)

```python
# 1) разложить N на цифры 9..2
# 2) если невозможно или нет чётной — -1
# 3) min по выбору последней чётной цифры
```

Крайние случаи: `N=1` → нет чётного без нуля/единицы в нашем правиле → `-1`; `N=8` → `8`.

## Слайд 5. Соседние идеи (для бонуса)

| Вариант | Идея |
|---------|------|
| Длина ≤ K | После жадности проверить `len ≤ K` |
| Палиндром | Набор должен позволить зеркало |
| Максимальное число | Мелкие цифры (больше длина) или сортировка по убыванию при фикс. длине |
| Сумма цифр = S | Другая жадность / ДП |
