# Блок 5. Стратегия олимпиады + микс  
*Презентация-конспект · 2 часа*

---

## Слайд 1. Как читать условие

1. **Что ввести / что вывести** (сначала!).
2. **Ограничения** → сразу оценить допустимую сложность.
3. Примеры: пересчитать руками **до** кодирования.
4. Особые слова: «минимальный», «хотя бы один», «если невозможно −1», «при равенстве меньший».

---

## Слайд 2. Порядок задач на туре

Рекомендуемый цикл (6 часов ≈ муниципальный):

1. Пробежать все условия (15–20 мин), пометить «легко / средне / трудно».
2. Решить все «легко» полностью.
3. Средние: идея на бумаге → код → стресс на своих тестах.
4. Трудно: частичные баллы / формула на маленьких / оставить на конец.

Не застревать > 40–50 мин без прогресса на одной задаче.

---

## Слайд 3. Тесты, которые стоит придумать самим

- Минимумы: n=1, пустые края.
- Граница перехода формулы (у кинотеатра 4↔5).
- Максимумы из ограничения (проверка TL/переполнения).
- «Невозможно» (−1).
- Ничьи (два ответа с одним счётом — правильный тай-брейк).

---

## Слайд 4. Черновик vs код

На бумаге зафиксировать:

- обозначения;
- формулу / инвариант;
- 2–3 своих теста.

В коде — сначала **честное** медленное решение для малых n (если успеваете), потом быстрое, сверить.

---

## Слайд 5. Частые ошибки Python

- `input().split` без `map(int, …)`.
- `print` лишних пробелов/строк.
- Рекурсия без `sys.setrecursionlimit` (на этом комплекте обычно не нужна).
- Путать `//` и `/`.
