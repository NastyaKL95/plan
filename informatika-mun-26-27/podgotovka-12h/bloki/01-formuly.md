## Слайд 1. Зачем формулы на олимпиаде

- Ограничение \(n \le 2\cdot 10^9\) → **нельзя** циклом по \(n\).
- Нужна **замкнутая формула** или \(O(\log n) / O(1)\).
- Типичный сюжет: «упаковать предметы с ограничениями на группы».

**Вопрос группе:** почему `for i in range(n)` при \(n=2\cdot10^9\) не взлетит?

## Слайд 2. Шаблон рассуждения

1. Обозначить параметр ответа \(p\) (число проходов, полок, дней…).
2. Написать, **сколько максимум** объектов помещается при данном \(p\).
3. Найти минимальное \(p\), при котором максимум \(\ge n\).
4. Аккуратно обработать **малые** \(n\) и целочисленное деление: \(\lceil a/b\rceil = (a+b-1)//b\) для \(a\ge0\).

---

## Слайд 3. Задача-образец: «Кинотеатр»

\(n\) кресел. Края ≤ 2, между проходами ≤ 5, хотя бы 1 проход. Минимум проходов.

При \(p\) проходах:

- 2 крайние группы ≤ 2;
- \(p-1\) средних ≤ 5;
- максимум кресел: \(4 + 5(p-1)\).

Ищем мин. \(p\ge1\): \(4+5(p-1)\ge n\).

---

## Слайд 4. Вывод формулы (на доске)

- Если \(n\le4\) → хватает \(p=1\).
- Иначе \(5(p-1)\ge n-4\) → \(p-1=\lceil(n-4)/5\rceil\).

```python
n = int(input())
print(1 if n <= 4 else 1 + (n - 4 + 4) // 5)
# (n-4+5-1)//5 == (n)//5 ... проверить на n=5,9,10!
```

**Проверка вместе:**

| n | 1 | 4 | 5 | 9 | 10 | 15 |
|---|---|---|---|---|----|----|
| ответ | 1 | 1 | 2 | 2 | 3 | 4 |

---

## Слайд 5. Типичные ловушки

- Пустая группа у края (n=1) — **разрешена**, если условие не запрещает.
- Путать \(\lfloor\rfloor\) и \(\lceil\rceil\).
- Формула верна только при \(n\ge1\); всегда смотреть примеры.
- Переполнение в C++ (`long long`); в Python спокойно.

---

## Слайд 6. Ещё одна модель (разобрать устно)

**Полки склада.** \(n\) коробок. На краях стеллажа ≤ 3, между разделителями ≤ 4. Минимум разделителей, ≥1.

Максимум при \(p\): \(6 + 4(p-1)\).  
При \(n\le6\) → 1, иначе \(1+\lceil(n-6)/4\rceil\).
