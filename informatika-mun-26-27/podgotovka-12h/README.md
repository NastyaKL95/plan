# Подготовка к олимпиаде по информатике — 12 часов

Интенсив для группы 9–11 классов. Опирается на типы задач муниципального этапа (формулы, цифры, массивы/распилы, комбинаторика на сетке) и наш комплект `informatika-mun-26-27`.

## Расписание (6 блоков × 2 часа)

| Блок | Часы | Тема | Материал |
|------|------|------|----------|
| 1 | 0–2 | Формулы и моделирование («Кинотеатр») | `bloki/01-formuly.md` |
| 2 | 2–4 | Цифры и конструкция числа («Чётный артикул») | `bloki/02-cifry.md` |
| 3 | 4–6 | Массивы, частоты, распилы («Трубы») | `bloki/03-massivy.md` |
| 4 | 6–8 | Комбинаторика на сетке («Катеты») | `bloki/04-kombinatorika.md` |
| 5 | 8–10 | Стратегия олимпиады + микс | `bloki/05-strategiya.md` |
| 6 | 10–12 | Тренировочный тур + разбор | `bloki/06-trenirovka.md` |

В каждом блоке: **теория → пример с разбором → практика → бонус для быстрых**.

## Файлы

- `programma.md` — подробный тайминг для преподавателя
- `bloki/` — презентации-конспекты (можно показывать с экрана)
- `praktika/` — задачи группы
- `bonus/` — доп. задачи для тех, кто решает быстрее
- `otvety-i-razbory.md` — ответы и краткие разборы
- `solutions/` — код к ключевым задачам
- `razdatochnyj-material.pdf` — краткая шпаргалка ученику
- Word/PowerPoint — в соседней папке [`../office/`](../office/):
  - `Programma_12_chasov.docx`, `Shpargalka_ucheniku.docx`, `Praktika_i_bonusy.docx`, `Otvety.docx`
  - `Prezentaciya_podgotovka_12h.pptx` (интенсив), `Prezentaciya_zadaniya_komplekt.pptx` (комплект задач)

## Как вести занятие

1. Не читать слайды дословно — писать на доске/в редакторе вместе с группой.
2. После каждого разобранного примера — 15–25 мин самостоятельной практики.
3. Кто закончил раньше — сразу `bonus/` (не ждать остальных).
4. В блоке 6 устроить мини-контест на 90 минут по 4 задачам из комплекта + 1 бонус.
