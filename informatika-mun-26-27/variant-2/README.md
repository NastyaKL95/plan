# Вариант 2 — муниципальный этап ВсОШ по информатике, 9–11 классы

Тренировочный комплект чуть сложнее примера: параметры в условиях, ограничения до \(10^{18}\), отрицательные числа,
ответ по модулю и подзадачи.

| Файл | Что внутри |
|------|-----------|
| [`zadaniya.md`](zadaniya.md), `zadaniya.pdf` | условия для участников |
| [`resheniya.md`](resheniya.md) | разбор решений с ловушками |
| [`solutions/`](solutions/) | эталонные решения на Python |
| [`tests/run_tests.py`](tests/run_tests.py) | примеры + сравнение с полным перебором |
| `office/Zadaniya_variant2.docx` | условия (Word) |
| `office/Razbor_variant2.docx` | разбор (Word) |
| `office/Prezentaciya_razbor_variant2.pptx` | презентация с разбором |

Пересборка Word/PowerPoint/PDF: `python3 build_office.py`.
