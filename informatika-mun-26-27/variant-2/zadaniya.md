## № 1. Зал с проходами — 100 баллов

В ряду концертного зала стоят \(n\) кресел. Между креслами нужно сделать один или несколько проходов.

- У каждой стены (в начале и в конце ряда) может стоять **не более \(a\)** кресел подряд.
- Между двумя соседними проходами может стоять **не более \(b\)** кресел подряд.
- В ряду должен быть **хотя бы один** проход.

Найдите минимальное число проходов.

### Формат входных данных

Три натуральных числа \(n, a, b\) через пробел (\(1 \le n, a, b \le 10^{18}\)).

### Формат выходных данных

Одно целое число — минимальное количество проходов.

### Примеры

| Вход | Выход | Пояснение |
|------|-------|-----------|
| `10 3 4` | `2` | 3 кресла, проход, 4 кресла, проход, 3 кресла |
| `11 2 5` | `3` | при двух проходах помещается только 2 + 5 + 2 = 9 кресел |
| `4 2 5` | `1` | 2 кресла, проход, 2 кресла |

### Подзадачи

| Баллы | Ограничения |
|-------|-------------|
| 30 | \(n \le 1000\), \(a, b \le 100\) |
| 30 | \(n, a, b \le 10^9\) |
| 40 | без дополнительных ограничений |

Процессорное время: 1 с · Память: 256 МБ

## № 2. Самый большой код — 100 баллов

Код сейфа — натуральное число, в записи которого **не больше \(K\) цифр**. Цифра 0 не используется.
Хозяин помнит только **произведение цифр** кода — число \(N\) — и то, что его код был
**наибольшим** из всех подходящих.

Найдите этот код или выведите \(-1\), если такого кода нет.

### Формат входных данных

Два натуральных числа \(N\) и \(K\) (\(1 \le N \le 10^{18}\), \(1 \le K \le 1000\)).

### Формат выходных данных

Наибольшее натуральное число не более чем из \(K\) цифр (без нулей), произведение цифр которого равно \(N\), или \(-1\).

### Примеры

| Вход | Выход | Пояснение |
|------|-------|-----------|
| `70 3` | `752` | 7·5·2 = 70; тройки цифр больше не найти |
| `70 5` | `75211` | единицы не меняют произведение, но делают число длиннее |
| `36 2` | `94` | 9·4 = 36 |
| `100 2` | `-1` | для 100 = 4·5·5 нужно минимум 3 цифры |
| `1 3` | `111` | |

### Подзадачи

| Баллы | Ограничения |
|-------|-------------|
| 25 | \(K \le 5\) (можно перебрать все числа) |
| 35 | \(N \le 10^6\), \(K \le 20\) |
| 40 | без дополнительных ограничений |

Процессорное время: 1 с · Память: 256 МБ

## № 3. Счастливые отрезки — 100 баллов

Дан массив из \(n\) целых чисел \(a_1, \dots, a_n\) (числа могут быть **отрицательными**) и натуральное число \(K\).
Отрезок массива \(a_l, a_{l+1}, \dots, a_r\) (\(l \le r\)) называется *счастливым*, если сумма его
элементов делится на \(K\) без остатка.

Посчитайте количество счастливых отрезков.

### Формат входных данных

В первой строке — числа \(n\) и \(K\) (\(1 \le n \le 2 \cdot 10^5\), \(1 \le K \le 10^9\)).
Во второй строке — \(n\) целых чисел \(a_i\) (\(|a_i| \le 10^9\)).

### Формат выходных данных

Одно целое число — количество счастливых отрезков (может не поместиться в 32-битный тип).

### Примеры

| Вход | Выход |
|------|-------|
| `5 3`<br>`1 2 3 4 5` | `7` |
| `4 2`<br>`-1 1 -1 1` | `4` |

### Подзадачи

| Баллы | Ограничения |
|-------|-------------|
| 20 | \(n \le 300\) |
| 30 | \(n \le 5000\) |
| 50 | без дополнительных ограничений |

Процессорное время: 1 с · Память: 256 МБ

## № 4. Квадраты на клетчатом поле — 100 баллов

Дано клетчатое поле из \(n\) строк и \(m\) столбцов клеток (то есть \((n+1)\times(m+1)\) узлов сетки).
Сколько существует квадратов, **все четыре вершины** которых лежат в узлах сетки?
Квадраты могут быть повёрнуты на любой угол — не только «ровные», стороны которых идут по линиям сетки.

Ответ может быть очень большим, выведите его по модулю \(10^9 + 7\).

### Формат входных данных

Две строки: число \(n\) и число \(m\) (\(1 \le n, m \le 10^9\)).

### Формат выходных данных

Одно целое число — количество квадратов по модулю \(10^9+7\).

### Примеры

| Вход | Выход | Пояснение |
|------|-------|-----------|
| `1`<br>`1` | `1` | |
| `2`<br>`2` | `6` | 4 квадрата 1×1, 1 квадрат 2×2 и 1 «ромб» с вершинами в серединах сторон |
| `3`<br>`3` | `20` | |
| `2`<br>`5` | `18` | |

### Подзадачи

| Баллы | Ограничения |
|-------|-------------|
| 30 | \(n, m \le 30\) |
| 30 | \(n, m \le 10^6\) |
| 40 | без дополнительных ограничений |

Процессорное время: 1 с · Память: 256 МБ
