=== ЗОФ 2026 ===

Тема сайта Забайкальского образовательного форума (zof.irozk.ru).

== Установка ==

1. Внешний вид → Темы → Добавить → Загрузить тему → выбрать zof-theme.zip → Установить → Активировать.
2. Настройки → Чтение: «Статическая страница», главная — «Добро пожаловать на Забайкальский образовательный форум – 2026».
3. Внешний вид → Меню: назначить меню в область «Главное меню». Если меню не назначено, в шапке показываются главная и страницы конкурсов.
4. Внешний вид → Настроить → Форум: дата очного этапа, ссылка на форму заявки и приказ, сроки этапов, логотипы партнёров, организаторы и контакты.
5. Внешний вид → Настроить → Свойства сайта: логотип и значок сайта. Логотип, выбранный в Astra, нужно выбрать заново: WordPress хранит его отдельно для каждой темы.

== Главная страница ==

Афиша с темой форума, датой, обратным отсчётом и текущим этапом; сроки проведения (текущий этап отмечается сам по датам); карточки конкурсов; текст главной страницы в блоке «О форуме»; призыв подать заявку, если задана ссылка на форму.

Сроки и тема уже есть в афише, поэтому их можно убрать из текста главной страницы, чтобы не повторять.

Карточки конкурсов строятся по страницам верхнего уровня. Порядок и состав можно задать в «Форум → Конкурсы». Число номинаций считается по первому списку на странице. Списки ссылок на страницах показываются карточками с номерами.
